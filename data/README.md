# Dataset

The dataset used in this research project contains responses to the
Patient Health Questionnaire-9 (PHQ-9) along with selected demographic,
behavioral, and lifestyle-related features.

The original dataset is not included in this public repository.

## Privacy Considerations

Mental-health-related questionnaire responses may contain sensitive
information. Therefore, the original dataset and any personally
identifiable or sensitive records are intentionally excluded from the
repository.

Users who want to reproduce the project should use an appropriately
sourced and anonymized dataset and ensure that its use complies with
applicable ethical, privacy, and data-use requirements.

## Expected Data

The project expects data containing PHQ-9 questionnaire responses and
the additional features used in the machine learning pipeline.

The exact feature names and preprocessing steps can be found in the
research notebook:

`Depression_detection_phq9.ipynb`
